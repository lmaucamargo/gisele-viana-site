# Gisele Viana — Neuropsicóloga

Landing page de Gisele Viana, psicóloga e neuropsicóloga (CRP 06/211913), com agendamento de horário pelo WhatsApp.

## Estrutura

- `index.html`: a página inteira, com o estilo e o script no próprio arquivo, sem dependências.
- `assets/img/`: fotos em WebP com reserva em JPG (480 px e ~900 px) e o QR code do WhatsApp.

## Publicar

É um site estático: suba a pasta como está em GitHub Pages, Netlify, Vercel ou qualquer hospedagem.

No GitHub Pages: Settings › Pages › Source: branch `main`, pasta `/ (root)`.

## Antes de publicar

- Trocar `https://www.giseleviana.com.br/` no `<head>` (canonical) pelo domínio real e usar o endereço completo na imagem de compartilhamento (`og:image`).
- Confirmar com a Gisele os dias de atendimento (segunda a sexta, em `workDays` no script) e os horários de cada período.
